How a project
moves through us

Four stages, in this order. You see the file at the end of each one.

Stage 01

Brief

We ask what the site has to do and who it has to do it for. You get a scope, a price, and a date.

Stage 02

Design

Structure first, then type, colour, and every state a screen can be in. Reviewed in the browser, not as a PDF.

Stage 03

Build

The same people write the front-end, so nothing gets lost translating a design into code.

Stage 04

Ship

Tested on real phones, handed over with the files, and we stay reachable after launch.
