# Phanuwat Audkanthar — Portfolio (v3)

ธีม **Depth Canvas** — ฉากหลังเป็นสนามอนุภาค 3 มิติที่ขยับตามเมาส์และการเลื่อนหน้า
ตัวหนังสือใหญ่แบบโปสเตอร์ สีเน้นสีเดียวคือ Electric Lime

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index-v3.html` | โครงหน้าและข้อความ (ชื่อ ประวัติ ช่องทางติดต่อ ฟอร์ม) |
| `styles-v3.css` | สไตล์ทั้งหมด |
| `app-v3.js` | canvas + อนิเมชัน + สร้างการ์ด + modal + ฟอร์ม |
| `data-v3.js` | **แก้ผลงาน ใบประกาศ ทักษะ ที่ไฟล์นี้ที่เดียว** |

ไฟล์ v1 และ v2 ยังอยู่ครบ ไม่ได้แตะ

## แก้เนื้อหายังไง

- **เพิ่มโปรเจกต์** → เปิด `data-v3.js` ก๊อปบล็อกใน `projects` ทั้งก้อนแล้วแก้
  `images` ใส่กี่รูปก็ได้ ถ้ามากกว่า 1 ปุ่มเลื่อนรูปจะโผล่มาเอง
  ใส่ `award: "GOLD MEDAL"` ถ้าอยากให้มีป้ายรางวัลมุมขวาบนการ์ด
- **เพิ่มใบประกาศ** → บล็อก `certificates`
- **แก้ทักษะ** → บล็อก `stack` · `level` มีได้ 3 ค่า:
  `excellent` (3 ขีด) · `good` (2 ขีด) · `learning` (1 ขีด)
- **แก้ชื่อ ประวัติ ที่อยู่ ฟอร์ม** → อยู่ใน `index-v3.html` ตรงๆ ค้นหาคำที่จะแก้ได้เลย
- **ตัวเลข 3 ตัวหน้าแรก** → `stats` ใน `data-v3.js`
- **แถบวิ่ง** → `ticker` ใน `data-v3.js`

จำนวนบนแท็บ (05 / 03 / 02 / 10) นับจาก `data-v3.js` อัตโนมัติ ไม่ต้องแก้เอง

## อนิเมชัน 12 ตัว

1. **Boot** — แถบโหลดพร้อม log วิ่ง กด SKIP หรือ Esc ข้ามได้ทุกเมื่อ (มีตัวตัดที่ 2.6 วิ กันค้าง)
2. **Depth field** — อนุภาคลอยเป็นชั้นความลึก มีเส้นเชื่อมเมื่อเข้าใกล้กัน
   เมาส์ผลักอนุภาคออก และทั้งสนามขยับสวนทางเมาส์แบบพารัลแลกซ์
3. **พุ่งไปข้างหน้าตอนเลื่อน** — เลื่อนเร็วแค่ไหน สนามก็วิ่งเข้าหาเร็วเท่านั้น
4. **Decode** — หัวข้อสุ่มตัวอักษรมั่วแล้วค่อยเข้าที่ ตัวไทยสุ่มด้วยพยัญชนะไทย
   ตัวอังกฤษสุ่มด้วยอักษรอังกฤษ (ตัด W กับ M ออก ตัวกว้างเกินจนบรรทัดยืด)
5. **ชื่อเลื่อนขึ้นจากใต้เส้น** — ตอนจบ boot
6. **เคอร์เซอร์เอง** — วงแหวนโปร่งบนลิงก์ทั่วไป จานทึบพร้อมป้ายบนการ์ด
7. **ปุ่มดูดเมาส์** — ปุ่มขยับเข้าหาเคอร์เซอร์เล็กน้อย
8. **แผงประจำตัวเอียงตามเมาส์** — เอียง 7 องศา พร้อมแสงวิ่งตามตำแหน่งเมาส์
9. **โผล่ตอนเลื่อนถึง** — การ์ดไล่กันขึ้นมาทีละใบ
10. **เส้นสแกน** — วิ่งลงบนรูปตอนเอาเมาส์ชี้การ์ด และวิ่งตลอดบนรูปโปรไฟล์
11. **แถบเลื่อนแท็บ** — ไฮไลต์ไถลตามแท็บที่เลือก
12. **นับเลข** — ตัวเลขหน้าแรกวิ่งจาก 0 ตอนเลื่อนถึง

ทั้งหมดปิดอัตโนมัติถ้าผู้ใช้ตั้งเครื่องว่าไม่อยากให้มีอะไรขยับ
(`prefers-reduced-motion`) canvas จะวาดภาพนิ่งเฟรมเดียวแทน

## สี่อย่างที่ตั้งใจทำแบบนี้

**1. ตัดข้อมูลปลอมของ v1 ออกหมด**
`index.html` เดิมยังมี Alex Vance / CyberPulse Inc. / San Francisco / 6+ Years /
12.4k commits ค้างอยู่จากเทมเพลต v3 ใช้ตัวเลขจริงจาก `data.js` แทน
(3 โปรเจกต์ · 500+ commits · 2 รางวัล) และตัดหน้า Resume ปลอมทิ้งทั้งหน้า
พอร์ตที่โกหกคนอ่านมีค่าติดลบ ไม่ใช่ศูนย์

**2. รูปใช้ `contain` ไม่ใช่ `cover`**
สกรีนช็อตมือถือเป็นแนวตั้ง ส่วนภาพหน้าจอคอมเป็นแนวนอน ถ้าครอปให้เท่ากันหมด
รูปแนวตั้งจะเหลือแค่ตรงกลาง เลยวางรูปเต็มใบไว้บนฉากหลังที่เป็นรูปเดียวกันแบบเบลอ
— เห็นครบทั้งใบ และที่ว่างข้างๆ ก็ไม่โล่ง

**3. เป็นสคริปต์ธรรมดา ไม่ใช่ ES module**
ดับเบิลคลิกเปิดไฟล์ตรงๆ (`file://`) ได้เลย ไม่ต้องรันเซิร์ฟเวอร์
(v1 ใช้ `import` ซึ่งเบราว์เซอร์บล็อกด้วยกฎ CORS เวลาเปิดแบบนี้)

**4. ฟอร์มติดต่อเปิดโปรแกรมอีเมลจริง**
หน้านี้ไม่มีเซิร์ฟเวอร์หลังบ้าน จะแกล้งขึ้นว่า "ส่งข้อความแล้ว" ก็ได้
แต่นั่นคือโกหกคนที่กดส่ง เลยให้มันเปิดโปรแกรมอีเมลพร้อมข้อความที่พิมพ์ไว้แทน
พร้อมบอกไว้ใต้ปุ่มตรงๆ ว่ามันทำงานยังไง

## ที่ทดสอบแล้ว (Chromium headless, 26 เคส ผ่านหมด)

- ไม่มีแถบเลื่อนแนวนอนตั้งแต่ 320px ถึง 1600px
- แท็บ · modal · เลื่อนรูป · ปุ่ม Esc / ← / → · Tab วนอยู่ใน modal เท่านั้น
- กด Tab ไปที่การ์ดแล้ว Enter เปิดได้ (การ์ดเป็น `<button>` จริง ไม่ใช่ div ที่ดักคลิก)
- ฟอร์มดักอีเมลผิดรูปแบบและข้อความสั้นเกินไป
- ปิด JavaScript แล้วรีเฟรช → ยังเห็นชื่อ ประวัติ และอีเมลครบ
- เปิดโหมด reduced-motion → การ์ดยังมองเห็นครบ ไม่มี error
